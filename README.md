# Biblioteca PDF — site gratuito

## Como adicionar PDFs

1. Coloque o arquivo PDF dentro da pasta `pdfs`.
2. Abra o arquivo `script.js`.
3. Dentro de `const pdfs = [ ... ]`, adicione uma linha como:

```js
{nome:"Meu PDF", arquivo:"pdfs/meu-pdf.pdf", categoria:"Cursos", descricao:"Descrição do documento."},
```

4. Salve e publique novamente no GitHub Pages.

## Publicar gratuitamente no GitHub Pages

1. Crie uma conta no GitHub.
2. Crie um repositório público.
3. Envie `index.html`, `style.css`, `script.js`, `README.md` e a pasta `pdfs`.
4. No repositório, abra **Settings → Pages**.
5. Em **Build and deployment**, escolha **Deploy from a branch**.
6. Selecione a branch `main` e a pasta `/ (root)`.
7. Salve.
8. O GitHub vai fornecer o endereço público do site.

## Atenção

Só publique PDFs que você tenha autorização para disponibilizar. Arquivos públicos podem ser copiados e compartilhados por outras pessoas.
